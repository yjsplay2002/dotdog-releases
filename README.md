# DotDog — Your desktop dog

A little dog that lives beside you while you work, for Windows and Mac.

- **Free without a time limit:** pet reactions, petting, fetch, naming and friendship.
- Full license: games, appearance customization, to-dos, Pomodoro, Relax, agent notifications and history.
- English and Korean UI. Windows 10/11 x64, macOS 12+ Apple Silicon and Intel.

[English website and downloads](https://lnrgame.com/dotdog/en#download) · [한국어 안내](https://lnrgame.com/dotdog) · [Latest release](https://github.com/yjsplay2002/dotdog-releases/releases/latest)
